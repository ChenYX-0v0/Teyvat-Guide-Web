# 06 · 开发路线图

## P0 · 骨架（已完成 ✅）

- [x] React + Vite + TS + Tailwind 4 工程
- [x] 路由 / 布局 / 主题色
- [x] Zustand 会话状态与乐观更新
- [x] Go + Gin 分层骨架（router / handler / service / repository / model）
- [x] 统一响应、Zap 日志、CORS、优雅退出
- [x] SQLite（pure-go）持久化与自动迁移
- [x] AIClient 抽象 + Mock / OpenAI 双实现
- [x] 健康检查与对话接口

## P1 · 核心能力

- [ ] 流式输出（SSE）：`POST /api/chat` 支持 `stream=true`，前端逐字渲染
- [ ] 会话管理：会话列表、重命名、删除、`GET /api/sessions`
- [ ] 用户体系：注册 / 登录 / JWT 刷新，接口接入 `middleware.JWTAuth`
- [ ] 知识库：角色 / 武器 / 材料数据表与导入脚本
- [ ] RAG 检索：向量库（pgvector 或 sqlite-vec）+ 召回增强回答

## P2 · 体验增强

- [ ] 图鉴页：卡片列表 + 筛选 + 详情
- [ ] 配队推荐器：基于角色池生成队伍
- [ ] 采集路线地图（Canvas / Leaflet）
- [ ] 移动端适配与 PWA
- [ ] 深色 / 浅色主题切换

## P3 · 工程化

- [ ] 前端单元测试（Vitest）+ 组件测试
- [ ] 后端单元测试（testify + sqlmock）
- [ ] CI：GitHub Actions 自动 lint / test / build
- [ ] Docker Compose：一键拉起前后端与数据库
- [ ] 可观测性：Prometheus 指标 + 链路追踪
- [ ] 数据库迁移工具（golang-migrate）

## 迭代节奏建议

| 阶段 | 周期 | 目标 |
| --- | --- | --- |
| P1 | 第 1～2 周 | 能真实回答原神问题、能看到历史会话 |
| P2 | 第 3～5 周 | 图鉴与工具成型，形成差异化 |
| P3 | 第 6 周起 | 稳定性、性能、可维护性 |
