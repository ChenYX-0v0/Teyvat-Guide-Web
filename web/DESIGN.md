# Design System：AI 提瓦特向导

> **这份文件是设计层的唯一真源（SSOT）**。改视觉规范 = 改这里 + 同步 `src/index.css` 的 token，**两处必须一致**。
> 代码里出现的任何"美化"如果和本文冲突，以本文为准；要偏离就先改本文（并在文末「变更记录」留一行）。
> 生成方式：结构借鉴 `taste-skill` 的 stitch 九节模板，取值全部来自本项目 `@theme`，**不是通用模板值**。

- 适用版本：`web/` 当前实现（React 19 + Vite 7 + Tailwind 4）
- 最后更新：2026-10-18

## 0. 配置旋钮（本项目的取值）

| 旋钮 | 取值 | 说明 |
| --- | --- | --- |
| **Creativity** | `3` | 我们是**工具**不是作品集。创意只体现在"材质的精确"，不体现在版式实验 |
| **Density** | `6` | 信息密度偏高（档案页一屏要看角色 + 面板 + 5 件圣遗物） |
| **Variance** | `2` | 版式高度可预测；**同一类东西在全站必须长得一样** |
| **Motion** | `3` | 只有反馈与入场两档时长，没有滚动编排、没有常驻微动效 |

> 页面模式对照（决定"该多克制"）：**首页 = Persuade**（可略放开）；**对话 / 账号 / 档案 = Operate**（克制优先）；**条款 = Read**。

## 1. 视觉主题与氛围

深色、冷调、克制的《提瓦特》材质语言：**页面像一块深色石板，卡片像嵌在石板里的金属铭牌**。

- 唯一强调色是**金**（原神 UI 的金），只用于主操作 / 选中 / 焦点 / 关键数字
- 七元素色**只做小面积标识**（圆点、角标、提示条），不做大面积铺色
- 材质来自 **内高光 + 冷调深阴影**，不靠玻璃拟态、不靠发光堆叠
- 背景有一层**极淡星尘点阵**与顶部金色柔光，用来打破"纯色块"的廉价感

一句话判据：**画面里最"亮"的东西，必须是用户此刻该点的那个东西。**

## 2. 色彩与角色

### 2.1 纵深（4 级，越靠前越亮）

| 语义 | Token | 值 | 用途 |
| --- | --- | --- | --- |
| L0 页面底 | `teyvat-ink` | `#0F1720` | `body` |
| L1 卡片 | `teyvat-panel` | `#16222E` | `Card` / 消息气泡 / 圣遗物卡 |
| L2 浮层 | `teyvat-panel-soft` | `#1D2B39` | 抽屉 / 体检面板 / 下拉列表 |
| L3 悬停·选中 | `teyvat-raised` | `#243545` | 导航选中、属性块高亮 |

### 2.2 填充 / 凹陷 / 遮罩

| 语义 | Token | 值 | 用途 |
| --- | --- | --- | --- |
| 输入底 / 内嵌块 | `teyvat-fill` | `rgba(255,255,255,.04)` | 输入框、属性格、`Card variant="inset"` |
| 悬停 / 展开 | `teyvat-fill-2` | `rgba(255,255,255,.07)` | 列表行 hover、图标按钮 hover |
| 栏底 | `teyvat-sunken` | `rgba(0,0,0,.28)` | 顶栏 / 侧栏 / 输入区（比页面更暗，让"栏"退后） |
| 遮罩 | `teyvat-scrim` | `rgba(0,0,0,.62)` | 弹窗 / 抽屉 / 移动端面板 |

### 2.3 金色（3 档，唯一强调色）

`teyvat-gold #D3BC8E`（主）· `teyvat-gold-deep #B89B63`（深）· `teyvat-gold-hi #F0E0BB`（高光）

**只允许出现在**：主按钮、选中态、焦点环、品牌名、关键数字（等级 / 评分 / 绑定 UID）。**禁止**用金铺大面积背景。

### 2.4 文字（4 级）

| 级别 | 值 | 用途 |
| --- | --- | --- |
| 主 | `#F5F1E8` | 标题、正文（**暖白，不用纯白**） |
| 次 | `rgba(245,241,232,.72)` | 次级正文、说明 |
| 弱 | `rgba(245,241,232,.48)` | 元信息、占位符 |
| 极弱 | `rgba(245,241,232,.30)` | 注释、禁用、页脚 |

### 2.5 描边（只有 2 种）

- 普通线 `teyvat-line` = `1px rgba(255,255,255,.08)`
- 强调线 `teyvat-line-strong` = `1px rgba(211,188,142,.28)`
- **语义例外**：错误 `#E5646C`、警告 `#E6B455`、稀有度 5★/4★/3★（这三类不算"第三种描边"）

### 2.6 元素色（7，只做小面积，直径 ≤ 28px）

风 `#74C2A8` · 岩 `#D9A441` · 雷 `#B08EE6` · 草 `#7EC236` · 水 `#4CC2F1` · 火 `#EF7A35` · 冰 `#9FD6E3`

### 2.7 稀有度

5★ `#D3BC8E` · 4★ `#B08EE6` · 3★ `#4CC2F1`（描边 40~45% + 文字用同色）

### 2.8 阴影（2 种，**必须带冷调色相，不用纯黑**）

| Token | 值 | 用途 |
| --- | --- | --- |
| `shadow-panel` | `inset 0 1px 0 rgba(255,255,255,.05), 0 10px 28px rgba(4,10,18,.55)` | 所有卡片 / 气泡 / 浮层 |
| `shadow-glow` | `0 0 0 1px rgba(211,188,142,.35), 0 6px 20px rgba(211,188,142,.18)` | 焦点环、主按钮悬停 |

> 阴影色相 = 页面底 `#0F1720` 压暗后的冷调，不是 `#000`。纯黑阴影在深蓝底上会发"脏"。

## 3. 字体规则

| 层级 | 规格 |
| --- | --- |
| 字体族 | `PingFang SC` / `Microsoft YaHei` / `system-ui`（**不打包字体、不联网字体**） |
| 字阶 | 10 / 11 / 12 / 13 / 14（正文）/ 16 / 17 / 18 / 20 / 22 / 24 / 30 / 48 |
| 字重 | **只有 400 / 500 / 600**（不要 700+：中文字体 700 多为合成加粗，会糊） |
| 行高 | 正文 1.55；小字 1.4；标题 1.25 |
| 字距 | 中文标题 `+0.01~0.04em`；全大写拉丁 `+0.18em`；数字 `tabular-nums` |

**版式职责**

| 元素 | 字号 / 字重 / 字距 |
| --- | --- |
| 品牌名 | 16（sm:17）/ 600 / +0.02em |
| 页面主标题 | 22 / 600 / +0.01em |
| 区块标题 | 13 / 600 / +0.04em，颜色 `text-2` |
| 正文 | 14 / 400 / 1.55 |
| 元信息、辅助说明 | 11~12 / 400 / 1.4 |
| 数字（等级 / 评分 / 属性 / UID） | 11~17 / 600 / `tabular-nums` |

**衬线：当前**不使用**。**
> 依据（2026-10-17 实测）：≥16px + 600 的衬线在开发机（装有 Noto Serif SC）上成立，但**多数用户回退到 SimSun**（只有 regular，600 会被合成加粗而发糊）；且衬线被铺到 14px 及以下时，比无衬线更虚、层级更弱。
> 结论：**软件 UI 用无衬线**；标题的"分量"靠字号 + 字重 + 颜色 + 字距，不靠换字体族。要重新引入衬线，必须先在本文件更新并附实测截图。

**标题断行**：`h1/h2/h3` 统一 `text-wrap: balance`（避免最后一行只剩一个字）。

## 4. 组件样式

> 所有组件都从 `src/components/common/` 取；**页面里不要手写 `border + bg + shadow` 三件套**。

| 组件 | 规格 | 状态 |
| --- | --- | --- |
| **Button** | `primary` 金底深字 + `shadow-panel`；`soft` `raised` 底 + 普通线；`ghost` 透明 + 线 + 悬停转金。尺寸：`sm` 高 32 / `md` 高 40，圆角 `lg` / `xl` | default / hover（`fill-2` 或金高光）/ active（下压 1px）/ disabled（40% + 不可点）/ focus（金 glow 环） |
| **Card** | `panel` 16 圆角 + 投影；`soft` 浮层用；**`inset` 12 圆角 + `fill` 底无投影**（卡片里的小块只能用这档） | `lift` 时悬停上移 2px + 金线 |
| **Chip** | 胶囊（`rounded-full`），`px-2.5 py-1 text-xs`；tone：neutral / gold / rarity-3·4·5；可带 6px 元素色圆点 | 静态 |
| **Input / Textarea** | 高 42、圆角 `xl`、`fill` 底、普通线；移动端字号 **≥16px** | hover 金线 / focus 金线 + glow / error 红线 / disabled 40% |
| **Modal** | 宽 640（`max-w-2xl`）、圆角 `2xl`、`panel` 底 + 金线；标题栏 13/600 金 + 下边线；`scrim` + 模糊 | blocking（不可 Esc / 点遮罩） |
| **Alert** | 圆角 `xl` + 1px 边框 + 12px 文案；tone：info（金）/ warn / error / ok；右侧可放操作 | `aria-live` 语义（error → `role=alert`） |
| **Skeleton** | `fill-2` 色块 + `animate-pulse`；形状必须**贴合真实内容**（行 / 卡 / 气泡） | `aria-hidden` |
| **EmptyState** | 金色线条图标框 48 + 主文案 14 + 说明 12 + 行动区；`py-12` 居中 | 静态 |
| **消息气泡** | 助手：`panel` + 左侧 2px 金色渐变竖条 + 投影 + 底部"AI 生成"标识；用户：金 12% 底 + 金线；圆角 `2xl`；最大宽 75% | 生成中（呼吸光标）/ 已停止 / 错误 |
| **会话行** | 高 36、圆角 `xl`；选中 `raised` + 500；行内操作**仅悬停显示** | hover / active / 重命名中 / 删除二次确认 |
| **圣遗物卡** | 圆角 `2xl`、`panel` 底、内边距 10（移动）/16（桌面）、**描边按稀有度**；评分行在顶部 | 5★/4★/3★ · 有/无评分 |
| **导航项** | 高 36（桌面）/40（移动）、圆角 `xl`；选中 `raised` + 左侧 3×16 金色圆条 | hover `fill-2` / focus glow |

## 5. 首页英雄区（非营销 Hero）

我们没有落地页，只有一屏"这是什么的说明"：

- 眉标 `TEYVAT GUIDE`：11px、`+0.24em`、极弱色
- 主标题 30/600 金色，**一句人话**（不写 slogan、不写"重新定义"）
- 主 CTA 只有一个金色按钮；次按钮只允许一个 ghost
- 状态行 12px：真实后端健康状态（**不做假绿灯**）
- 下方是"开发进度"三张卡（状态板）：卡高亮只有状态 Chip，不整卡染色

**禁止**：滚动提示箭头、大段口号、居中堆叠、装饰性插图。

## 6. 布局原则

| 项 | 规则 |
| --- | --- |
| 栅格 | 只用 8pt 网格：4/8/12/16/20/24/32/40/48/64 |
| 内容宽度 | 账号 / 首页 `max-w-5xl`（1024）；对话页**满宽**（三栏）；条款 `max-w-3xl` |
| 外壳 | 顶栏 **56**（`h-14`）· 侧栏 **224** · 会话列表 **256** · 页脚 **28** |
| 圆角 | **只有 3 档 + 全圆**：`lg 8`（小控件）/ `xl 12`（按钮·输入·行）/ `2xl 16`（卡片·气泡·弹窗）/ `full`（胶囊·圆） |
| 层级 | 页面（ink）→ 卡片（panel）→ 卡片内的块（inset）→ 浮层（panel-soft）。**禁止卡片套卡片再套卡片** |
| 页面内边距 | 移动 16 / 桌面 24；区块间距 24 或 32 |
| 对齐 | 同屏的同一类元素**必须同高、同基线**；图标与文字的视觉对齐允许 1~2px 手工修正 |

## 7. 响应式规则

- 断点只用 `sm 640` / `md 768`；**必须过 375 / 390 / 768 / 1440 四档**
- 页面高度用 `h-dvh`（不用 `100vh` / `h-full`），底部固定元素补 `env(safe-area-inset-bottom)`
- 移动端折叠：侧栏 → 抽屉（256，`scrim` 遮罩）；会话列表 → 抽屉；圣遗物 5 列 → 2 列；属性 4 列 → 2 列
- **输入类元素移动端字号 ≥16px**（否则 iOS 聚焦会放大整页）
- **触控目标 ≥44×44**：小图标按钮用 `.tap-44`（透明外扩，不改视觉尺寸）；行内操作为已知例外（24~28，靠悬停显隐 + 键盘可达）
- 任何横向溢出都算 bug；`scrollWidth` 必须等于视口宽

## 8. 动效意图

| 场景 | 时长 / 曲线 |
| --- | --- |
| 悬停、按下、颜色 | `140ms` · `cubic-bezier(.22,1,.36,1)` |
| 展开、入场、面板出现 | `220ms` · 同上；位移 ≤ 6px |
| 生成中光标 | 呼吸 1.1s 循环 |
| **不做** | 弹跳、弹性、旋转进场、滚动编排、常驻微动效、超过 300ms 的 UI 动效 |

- 按下统一 **下压 1px**（不用 `scale`：工具型界面里缩放会让整行文字抖）
- 焦点环统一金色 glow（键盘可达性是硬要求，不是"加分项"）
- **必须**尊重 `prefers-reduced-motion`（已在 `index.css` 全局处理）
- 进场只加在"首屏内容 / 面板 / 列表项"，不逐元素编排

## 9. 反模式（本项目禁用清单）

### 9.1 我们**已经踩过**的坑（重点）

| 坑 | 现象 | 正确做法 |
| --- | --- | --- |
| **装饰不分层** | 全站同一种圆角暗卡 + 同一种金边 → 再精致也"通用" | 功能层克制、内容层才做材质 |
| **衬线铺满** | 标题、区块标题、属性值、UID 全换衬线 → 小字发虚、界面像文档 | 软件 UI 不用衬线；分量靠字号/字重 |
| **字体栈没考虑回退** | 开发机有 Noto Serif，用户回退 SimSun → 合成加粗发糊 | 只用系统无衬线 |
| **元素色铺面积** | 用元素色做大色块 → 廉价 | 元素色只做 ≤28px 标识 |
| **散装透明度** | `bg-white/[0.03]` `[0.04]` `[0.06]` `bg-black/25` 混用 | 只用 fill / fill-2 / sunken / scrim 四档 |
| **卡片套卡** | 卡片里再套完整卡片（带投影 + 16 圆角） | 内层用 `Card variant="inset"` |

### 9.2 通用 AI tell（一眼假）

- 紫色渐变 / 蓝紫 mesh 背景
- 三张等宽功能卡当首屏（我们首页的状态板是**状态语义**，不是 feature 卡，允许）
- 纯 `#000` 背景、纯 `#FFF` 文字
- 第 4 种圆角、第 3 种描边、纯黑阴影
- 每个按钮都 filled、每个卡都带"New / Beta"胶囊
- 雪花式渐变、玻璃拟态堆叠、发光外框滥用
- 插画 / 3D 渲染 / AI 生成人物立绘（版权 + 观感双重风险）
- 文案里的 "赋能 / 无缝 / 一站式 / 重新定义"
