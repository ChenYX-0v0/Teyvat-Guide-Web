# Pixso 设计稿生成指令（AI 提瓦特向导 · C 端）

> **用途**：直接发给 Pixso（AI 生成 / 或发给设计师）的完整设计需求。
> **怎么用**：
> 1. 先发 **附录 A（短指令）** —— 让 Pixso 建好画布与设计系统；
> 2. 再按 **附录 B** 逐页发（一次一页，质量远高于"一次生成全套"）；
> 3. 把 `deploy/out/pixso-ref/` 里的 **5 张基准截图** 作为参考图拖进同一画布（只作布局参考，**不要照抄字体**，见 §4.2）；
> 4. 生成后按 **§10 交付要求** 和 **§11 自检** 逐条核对。
>
> **本文件的两个"真源"**：结构 = 当前线上代码（`web/src`），视觉 = `web/src/index.css` 的 `@theme` token。**颜色 / 圆角 / 时长一律照抄，不要自由发挥。**

## 1. 一句话任务

为「AI 提瓦特向导」设计 **C 端 Web 产品**（深色、原神主题、AI 问答 + 玩家档案分析）的完整 UI 设计稿：
**11 个页面 × 桌面 1440 + 移动 390 两套**，含设计系统页、组件库页、六种界面状态。

## 2. 产品与业务（给设计看的背景）

| 项 | 内容 |
| --- | --- |
| 产品 | 《原神》主题的 AI 助手。用户用自己的游戏 UID 查档案，AI 结合**真实展柜角色**回答问题 |
| 用户 | 原神玩家（中文，Windows 桌面为主 + 手机浏览器）。**邀请制**，不公开注册 |
| 核心链路 | ① 登录 → ② 绑定游戏 UID（查询即绑定） → ③ 看自己的角色 / 圣遗物 → ④ 问 AI（可基于自己角色） → ⑤ 看会话历史 |
| 第二个入口 | **游客演示区**（免登录，内容全预置）：先看到产品长什么样，再决定登录 |
| 合规硬要求 | ① 页面底部**常显 ICP 备案号**；② 用户须知（含阻断式确认弹窗，须阅读 5 秒）；③ 每条 AI 回答末尾标「内容由 AI 生成，仅供参考」 |
| 明确不做 | 不做社区 / 不做攻略站 / 不做氪金推荐 / 不做账号交易 / 不做多语言切换（中文优先，英文仅文案层） |

**产品性格**：像一个**懂行的向导**，不是"AI 聊天机器人"。克制、精确、有材质感；不卖萌、不炫技、不堆装饰。

## 3. 技术栈与实现约束（设计必须可落地）

| 约束 | 具体 | 对设计的要求 |
| --- | --- | --- |
| React 19 + TypeScript + Vite 7 | 无 UI 组件库（不用 antd/MUI） | 所有控件**自绘**，尺寸/间距必须能落成 Tailwind 类 |
| Tailwind CSS 4 | 断点：`sm`=640、`md`=768（默认） | 只做 **375 / 390 / 1440** 三档核对；不要设计"只在 1024 好看"的布局 |
| 主题 | **深色单主题**（`color-scheme: dark`） | 不需要浅色版；不要出现纯白大面积 |
| 单位 | 8pt 网格 | 间距只用 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64 |
| 高度 | `h-dvh`（动态视口） | 移动端底部固定元素要留 `16px + 安全区` |
| 移动端输入框 | 字号 ≥16px | 输入类控件在 390 稿上标 16px，**不要标 14px** |
| 图标 | lucide-react（线性图标） | 统一 1.5~2px 描边，尺寸 16 / 20 / 24；**不要彩色图标、不要实心图标混用** |
| 动效 | 只有两档：**140ms（悬停/按下）**、**220ms（展开/入场）** | 标注时长时只写这两个数字，三档以上会被打回 |
| 圆角 | **只有 3 档 + 全圆**（见 §4.4） | 出现第 4 种圆角即视为不合格 |

## 4. 设计系统（照抄，不要改数值）

### 4.1 颜色（唯一来源：`@theme` token）

**底色 / 层级（4 级，越靠前越亮）**

| 名称 | Hex | 用途 |
| --- | --- | --- |
| ink（L0） | `#0F1720` | 页面底 |
| panel（L1） | `#16222E` | 卡片 |
| panel-soft（L2） | `#1D2B39` | 浮层 / 抽屉 / 分析面板 |
| raised（L3） | `#243545` | 悬停 / 选中 |

**金色（唯一强调色，3 档）**：`#D3BC8E`（主）/ `#B89B63`（深）/ `#F0E0BB`（高光）
> 金色只出现在：主按钮、选中态、焦点环、关键数字、品牌名。**不许用金色铺大面积背景。**

**文字（4 级）**：`#F5F1E8`（主）/ `rgba(245,241,232,.72)` / `rgba(245,241,232,.48)` / `rgba(245,241,232,.30)`
> 正文不要用纯白 `#FFFFFF`。

**描边（只有 2 种）**：普通 `1px rgba(255,255,255,.08)`；强调 `1px rgba(211,188,142,.28)`
> 禁止 `2px` 以上的描边、禁止纯白描边、禁止彩色描边（例外：错误态 `#E5646C`、稀有度色）。

**元素色（7 种，只做小面积标识，直径/宽度 ≤ 28px）**

| 元素 | Hex | 元素 | Hex |
| --- | --- | --- | --- |
| 风 | `#74C2A8` | 火 | `#EF7A35` |
| 岩 | `#D9A441` | 冰 | `#9FD6E3` |
| 雷 | `#B08EE6` | 水 | `#4CC2F1` |
| 草 | `#7EC236` | | |

**稀有度（沿用原神约定）**：5★ `#D3BC8E` / 4★ `#B08EE6` / 3★ `#4CC2F1`
**状态色**：成功 `#7EC236` / 警告 `#E6B455` / 错误 `#E5646C`

**阴影（只有 2 种）**
- `panel`：`inset 0 1px 0 rgba(255,255,255,.05), 0 8px 24px rgba(0,0,0,.35)` —— 所有卡片
- `glow`：`0 0 0 1px rgba(211,188,142,.35), 0 6px 20px rgba(211,188,142,.18)` —— 只给焦点态与主按钮悬停

### 4.2 字体

| 层级 | 规格 |
| --- | --- |
| 字体族 | `PingFang SC` / `Microsoft YaHei` / system-ui（**无自托管字体**） |
| 字阶 | 10 / 11 / 12 / 13 / 14（正文默认）/ 16 / 18 / 20 / 24 / 30 / 48 |
| 字重 | **只有 400 / 500 / 600**（不要 700/800/900，中文会糊） |
| 行高 | 正文 1.55；小字 1.4；标题 1.25 |
| 字距 | 中文标题 +0.04em；全大写拉丁 +0.18em |

**标题用衬线，正文用无衬线**（这是产品的识别点，也是"去 AI 味"的关键）：

| 用在哪 | 字体 | 字号 / 字重 |
| --- | --- | --- |
| 品牌名「AI 提瓦特向导」 | **衬线**（`Noto Serif SC` → `Songti SC` → `SimSun` 回退） | 16 / sm 18 · 600 · +0.06em |
| 页面主标题（账号信息 / 智能问答 / 演示档案…） | 衬线 | 21 · 600 · +0.05em |
| 首页大标题「欢迎来到提瓦特，旅行者」 | 衬线 | 24 / sm 30 · 600 · +0.05em |
| 玩家昵称、404 数字、条款标题 | 衬线 | 16 / 48 / 20 · 600 |
| 区块标题（已收录角色、角色面板、圣遗物 5 件） | 无衬线 | 14 · 500 · +0.02em |
| 所有数字（属性值 / 评分 / +20 / 等级 / UID） | 无衬线 + `tabular-nums` | 11~16 · 600 |
| 正文 / 按钮 / 输入 / 标签 | 无衬线 | 12~14 · 400/500 |

> ⚠️ **衬线只能出现在 ≥16px 的标题上**。14px 及以下用衬线会发虚、层级更弱——这条是实测结论，不要"为了统一"把衬线铺到小字上。

### 4.3 间距与栅格

| 场景 | 数值 |
| --- | --- |
| 页面左右内边距 | 移动 16 / 桌面 24 |
| 卡片内边距 | 移动 10~16 / 桌面 16~20 |
| 卡片间距 | 24（区块之间）、8~12（同类项之间） |
| 桌面内容最大宽 | 1024（账号/首页）、满宽（对话页） |
| 桌面侧栏 | 224（会话列表 256） |
| 顶栏高 | 56（桌面）/ 56（移动，含汉堡） |
| 页脚高 | 28（备案号一行） |

### 4.4 圆角（**只有 3 档 + 全圆**）

| 档位 | 值 | 用在哪 |
| --- | --- | --- |
| lg | **8px** | 小控件：图标按钮、小标签、头像图、内嵌小块 |
| xl | **12px** | 控件：按钮、输入框、列表行、菜单项、头像框 |
| 2xl | **16px** | 容器：卡片、面板、弹窗、消息气泡 |
| full | 999px | 胶囊、圆点、头像环、开关（**不是"角"**） |

> 全稿只允许出现这 4 类圆角值。**不许出现 4px / 6px / 10px / 20px / 24px。**

### 4.5 图标与图像

- 图标：线性、1.5px 描边、`currentColor`；尺寸 16（行内）/ 20（按钮）/ 24（徽记）
- 头像：圆形，40 / 48 / 56 三档
- 角色头像：方形圆角 8px，48 / 64
- **不要**插画、不要 3D 渲染图、不要人物立绘、不要 AI 生成的角色图（版权 + 观感都是风险）；需要"原神感"用**几何符号与线条**解决
